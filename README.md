## Program Controls

### Arrow Controls
  * **Left** and **Right**: Move Mario side to side
  * **Up**: Jump
  * **Down** Crouch

### Key Controls
  * **R**: Resets Mario to the beginning
  * **X**: Activate Christmas mode
  * **Shift**: Mario sprints
  * **M**: Mute game
  * **P**: Pause game
  * **D** (Hold): Activates Invincible Mario
  * **Space**: Activate Teleport Dash Mario

### Inspiration
With the hoilday season, our team thought there would be no better way to end off the semester with our own christmas-themed chaos Mario level. Each team member added their own feature into the game, granted that it fit into the Christmas theme.
